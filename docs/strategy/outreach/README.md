# outreach/

対外・打診・提案ドキュメント置き場。

## 必須構成（大前提）

相手が SuzuPay / Portal を知らなくても読めること。次の3つが欠けたまま出さない。

1. **前提整理** — 誰向けか、いま何が起きているか、なぜ今この話か、約束しないこと  
2. **プロダクト説明** — 何の層があるか（調査AI / ポータル / 決済）、それぞれの役割、体験の流れ  
3. **ビジョン説明** — うまくいったときの姿（定性で可。未確定KPIは断定しない）

そのうえで Ask・デモ順・信頼ルールを付ける。

正本が Drive にある場合は先頭に Drive URL を書く。

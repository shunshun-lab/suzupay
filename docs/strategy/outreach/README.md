# outreach/

対外・打診・提案ドキュメント置き場。

## 必須構成（大前提）

相手が SuzuPay / Portal を知らなくても読めること。次が欠けたまま出さない。

1. **前提整理** — 誰向けか、いま何が起きているか、なぜ今この話か、約束しないこと  
2. **プロダクト説明** — 何の層があるか（調査AI / ポータル / 決済）、それぞれの役割、体験の流れ  
3. **ビジョン説明** — うまくいったときの姿（定性で可。未確定KPIは断定しない）  
4. **着地** — 誰のどの席に、何を置いて、どう終わるか（主着地＋必要なら並行トラック）

そのうえで Ask・デモ順・信頼ルールを付ける。

## 共感パートのレビュー（厳守）

「いま起きていること」「なぜこの話か」など **共感が主目的の見出し**は、一般論・当たり前で進めない。

- **必須:** 具体例 ＋ 出典付き数字（無ければ `UNKNOWN／未取得` と明示）
- **不合格:** 「候補は多いが見えない」だけ、政策スローガンの复唱だけ、固有名も数字もないまま次へ
- **レビューラベル:** `NG一般論` / `要出典` / `FACT不足`

詳細レシピ: skill `external-outreach-docs`

正本が Drive にある場合は先頭に Drive URL を書く。

# outreach/

対外・打診・提案ドキュメント置き場。

## 必須構成（大前提・欠けたら未完成）

相手が SuzuPay / Portal を知らなくても読めること。

1. **前提整理** — 誰向け／いま何か／なぜ今／約束しないこと  
2. **目的の分解** — 上位目的 → 下位目的（誰の行動がどう変わるか）→ 非目的。部品から入らない  
3. **想定ペルソナ** — 最低2（来訪者＋実務/政策など）。「関係者全般」禁止  
4. **ユーザージャーニー** — ペルソナごとに時系列。来訪者は推奨→参加→決済を通す  
5. **ビジョン** — うまくいった姿（定性。未確定KPI断定禁止）  
6. **プロダクト** — 鎖でつなぐ（部品カタログのみ禁止）。目的↔部品の対応  
7. **着地** — 誰のどの席に何を置いてどう終わるか（主＋並行）

### 共感パート

「いま起きていること」等は一般論禁止。具体例＋出典付き数字（なければ UNKNOWN）。

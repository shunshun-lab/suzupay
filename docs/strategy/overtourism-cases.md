## A. すでに効果検証まで出ている先進事例（事例集側）

「企画として採択された」ではなく、**数字や失敗まで出ている層**。LocalManus / ポータルの型を取るならここから。

### 宮島・廿日市 — 行動誘導の型（最重要参照）

デジタルマップ ＋ スタンプラリー ＋ 駐車場混雑 LED。

- 「混んでるから来るな」ではなく、**ゲームで非混雑スポットへ動かす**
- 16日間で 1,147 人参加
- 写真撮影要素を使った参加者は、使わなかった参加者より滞在時間・スタンプ取得が約 3 倍
- 表参道商店街利用者の 1/3 以上が非混雑スポットにも移動

転用の核: 混雑表示 → **インセンティブ付き行動変容**。

### 京都市 — 交通誘導 ＋ 住民納得の型

観光特急バス誘導、東山の車迂回、市民向けポータル「LINK! LINK! LINK!」。

- 東山丸太町交差点への北側流入が対策前後で約 9% 減
- 観光効果・市民限定特典・交流を市民向けに発信
- **観光客管理 ＋ 市民エンゲージメント**を同じ設計に載せる

### 小樽市 — 地域OSの型

GPS 人流、早朝観光、手荷物配送、バス停カメラ/スピーカー、市民向け「恩恵の見える化」。

- 早朝ツアー 7:00 / 7:30 の 2 コースで計 179 人
- データ → 分散施策 → 物流まで一連で組む

### 美瑛町 — 生活圏衝突の型

混雑可視化カメラ、駐車場、農地侵入防止、デジタルサイネージ、地域ピクトグラム。

- 青い池集中だけでなく、**農地への無断侵入**が農業経営に影響している問題を正面から扱う
- 観光DXというより、行動・土地利用・住民生活の一体設計

### 鎌倉・藤沢 — 失敗が公開されている型

撮影スポット誘導・交通誘導・ごみ袋配布。

- 鎌倉高校前踏切: スポット外撮影者を 30% 減が目標 → 実際は **12.6% 増**
- 誘導員・看板だけでは行動は十分に変わらない、という反証

### 宮島口 — リアル空間インフラ統合

約 200 インチ LED ＋ 駐車場・観光データ統合。情報を街のハードに出す層。

| 地域 | やっていること | 転用ポイント |
|------|----------------|--------------|
| 宮島・廿日市 | マップ＋スタンプ＋駐車場LED | ゲームで人を動かす |
| 京都市 | 特急バス・迂回・市民ポータル | 住民納得をKPI化 |
| 小樽市 | GPS・早朝・手荷物・混雑検知 | 地域OSとして組む |
| 美瑛町 | カメラ・駐車場・農地侵入防止 | 観光×生活圏衝突 |
| 鎌倉・藤沢 | 撮影誘導など | うまくいかない実験も資産 |
| 宮島口 | 大型LED＋データ統合 | 街の情報インフラ |

## B. 令和8年度（2026）新規採択 — 企画段階として見る

今年度案件。先進的な企画として採択されたもの。**成果実証済みとは分けて読む。**

## C. 思想の一本線（観光庁案件全体の進化）

```
混雑を表示する
  → データで予測する
  → 別の場所・時間をレコメンドする
  → ポイント・体験・交通・物流で実際に行動を変える
  → 結果を住民にも還元・可視化する
```

高木側の地域構想に寄せる最短合成:

**宮島の行動誘導 ＋ 小樽の人流データ ＋ 京都の住民向けポータル**

観光客だけを見るのではなく、住民・事業者・来訪者の関係をデータ化し、地域側が介入できる基盤まで持っていく。

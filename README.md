# Suzupay（鈴ペイ）

SuzuPay は、インバウンド旅行者・地域店舗・地域運営者をつなぐ地域経済インフラ / regional operating layer を目指すプロジェクトです。

原点はステーブルコイン × QR 決済ですが、現在は **地域発見 → 回遊 → 参加 → 決済 → データ → 再訪** までを一体化する方向へ拡張しています。
